# ダウンロード・チャイム

## インストール
1. このフォルダを削除・移動しない場所に置きます。
2. Chromeのアドレス欄に `chrome://extensions` と入力します。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、この `download-chime` フォルダを選択します。
5. 拡張機能のアイコンを押し、「完了音を試す」で確認します。

Chrome 116以降。元のDownload Soundも有効な場合、通知が重複するのでそちらをオフにしてください。

## 機能
完了チャイム・失敗チャイム、音量、日本語読み上げ、デスクトップ通知、失敗通知の切替。音のテスト時も現在の設定を保存します。手動キャンセルも中断として通知します。Chromeで管理されるダウンロードが対象で、サイト内の生成処理の完了は検知しません。大量の同時完了では音を順番に再生します。

## プライバシーと権限
外部サーバー通信・アクセス解析・Webページへの挿入はありません。設定はstorage.localに保存します。downloadsは完了検知と通知用のファイル名取得、notificationsは画面通知、offscreenはウィンドウを開かない音声再生、ttsは端末内の日本語読み上げに使用します。downloads権限はChromeの仕様上、ダウンロード管理全体への権限です。ファイル内容は読みません。通知にはファイル名が出るため、不要なら画面通知をオフにしてください。読み上げはローカル日本語音声がない場合エラーになり、通知音へ切り替えて利用できます。OSの消音・集中モード・通知設定によって聞こえない／表示されない場合があります。

## 実装
Download Sound 1.7の機能と調査結果を参考に新規実装しました。元のコード・音源・アイコンは同梱していません。Manifest V3のoffscreenドキュメントで通知音を再生します。ストアとの自動更新設定はなく、このフォルダを更新後、拡張機能画面で再読み込みします。

参考: https://developer.chrome.com/docs/extensions/reference/api/offscreen

## 検証結果
検証用Chromeで拡張読み込み・設定保存・完了音／失敗音の再生・offscreen利用を確認。430px／1200pxの設定画面を目視確認。通知条件（完了・失敗・無効・失敗通知オフ）をモックテストで確認。実ダウンロードの自動テストは応答待ちで停止したため未確認。OSでの通知表示・実際に聞こえる音量・日本語読み上げは利用環境で確認してください。
